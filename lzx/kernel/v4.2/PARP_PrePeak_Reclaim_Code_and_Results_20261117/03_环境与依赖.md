# 当前环境与依赖（2026-11-19）

本轮理想实验代码使用Python标准库；不依赖已训练模型、PyTorch、GIMP或LibreOffice。源目录是 `workspace/PARP_Prediction_Contract_Study_20261119`。离线复核支持Python3.10及以上；实际内存实验需要Linux、cgroup-v2 memory控制器、普通用户桌面会话和本地sudo隔离组设置。

本次VM：Ubuntu22.04、Linux6.17.13；隔离组总上限2GiB、禁用该组swap，实验冷池512MiB干净文件映射。未更改全局内存压缩开关。结果不能推广到匿名压缩/换出。

只读核对：[INPUT_AVAILABILITY.json](workspace/PARP_Prediction_Contract_Study_20261119/results/INPUT_AVAILABILITY.json)。内核 `CONFIG_IDLE_PAGE_TRACKING=y`，Page Idle位图存在，但qi普通用户不能读写；`CONFIG_DAMON`未启用。pagemap文件可读不代表普通用户能取得PFN。

需求计数器已有读取接口；真实页访问/重访采集、开销和有效性检查仍需实现。页采集所需权限应由采集人员在受测VM本地设置，不需要提交密码或凭据。具体字段、标签和方法见 [采集规格](workspace/PARP_Prediction_Contract_Study_20261119/交给采集人员的字段与步骤.md)。

原包中GIMP/Krita/LibreOffice与资产路径是2026-11-17历史实应用实验的依赖，保留原样；并非本轮理想实验的运行依赖。旧版环境说明：[history/release-20261117/03_环境与依赖.md](history/release-20261117/03_环境与依赖.md)。
