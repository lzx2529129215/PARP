# 环境与依赖

## 包内已提供

- 最新运行源码、控制器、测试和本批原始结果。
- 11 月 13 日历史候选额度、基线、参考和源码。最新服务会验证其原始哈希，并把它们作为候选证据；不会直接把旧表当成新策略已通过。
- GIMP 原生负载、Krita 输入到可见探针、GUI 辅助包、cgroup 启动器。
- 临时任务通道引用的冻结清单及其 10 个历史源码文件。
- 当前 Firefox 的路径、版本与校验信息，见主代码 `lab/firefox-install.json`。
- 本批实时日志、宿主机内存采样、恢复和临时通道退出记录。

`workspace/parp-wss-v5` 仅含哈希检查所需文件，不是完整可编译的内核树。旧 GUI/历史目录是依赖，不是另一个最新策略入口。

## 实机运行仍需现有虚拟机提供

这是代码、证据和说明包，不包含虚拟机磁盘、应用安装包或全部大型测试资产。原实验环境为普通桌面用户 qi（UID 1000）的 Ubuntu 虚拟机，内核版本见各轮 `kernel` 字段；本批记录为 6.17.13。

| 依赖 | 本版用途/原有位置 |
|---|---|
| cgroup v2 memory 控制器与用户会话委派 | memory.current/high/max/reclaim、memory.pressure、memory.stat 等接口 |
| zswap 及可用 swap | 采集辅助程序在实验期间开启，结束后恢复原设置 |
| GIMP、Krita、LibreOffice Calc、Firefox | 原生应用负载；Calc 还需要系统 Python 的 UNO 模块 |
| Xephyr、openbox、xauth、xdpyinfo | 创建私有 X11 显示环境 |
| xdotool、wmctrl、xprop、xwininfo、tesseract | GUI 探针和界面验证 |
| Python 3.10 以上 | 用户态控制与本地分析；Ubuntu GUI 探针还使用现有虚拟环境 |
| Python GUI 包 | PyAutoGUI、OpenCV、Pillow、python-xlib；已有固定版本清单在 `foreground_krita_gui/requirements.txt` |
| GUI 虚拟环境 | `/home/qi/krita-acceptance-venv/bin/python` |
| 测试资产 | `/home/qi/krita-userspace-realapps-20261105/assets`，至少包含本负载使用的 ORA 图像与 GIMP 素材 |
| Krita 私有配置模板 | `/home/qi/krita-userspace-peak-20261103/profile-template` |
| 私有 Firefox | 以主代码 `lab/firefox-install.json` 中的 executable 为准；没有替换系统 Firefox |

GUI 输入依赖普通用户桌面会话，不能把整套原生应用试验直接作为 root 运行。Windows 上可以运行离线测试、汇总与完整性核验；不能在 Windows 上直接操作 Linux cgroup。

换机器需要重新准备上述环境并重新校准，不能沿用资格文件声称新环境已经通过。这个包没有安装任何程序、修改系统配置或启动新的实机实验。
