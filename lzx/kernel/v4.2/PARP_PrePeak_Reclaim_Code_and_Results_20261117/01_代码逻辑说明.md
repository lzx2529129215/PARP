# 当前代码逻辑入口（2026-11-19）

最新实现位于 [`workspace/PARP_Prediction_Contract_Study_20261119/`](workspace/PARP_Prediction_Contract_Study_20261119/)。完整说明见 [预测接口与代码改动](workspace/PARP_Prediction_Contract_Study_20261119/预测接口与代码改动.md)。

1. 应用间脚本输出预计使用的应用、时间与保护分数。
2. 应用内脚本按本轮时刻t输出[t,t+H]的40个未来窗口：WSS、占用增量和缺页次数，以及安全冷量/有效期。
3. 适配层对齐各应用同一时刻的占用变化，与实时剩余空间计算缺口，不相加各应用不同时刻的独立最大值。
4. 固定high由独立参考配置给出；reclaim按测得释放能力安排在增长前完成，保留原预算及保护规则。
5. 内核接口真正回收，再用实际占用、重访与PSI反馈修正。实际已发生增长不再重复计入未来需求。

主要文件：`prediction_contract.py`（输出与理想提供器）、`study_pipeline.py`（完整接线及实际反馈）、`scheduler_fix.py`（峰值切换修正）、`controller/`（原版控制器）。

未来模型替换理想提供器，必须遵循 [输出合同](workspace/PARP_Prediction_Contract_Study_20261119/OUTPUT_CONTRACT.json)。原GitHub的四操作WSS/缺页查表接口没有被冒充为已经实现该滚动格式，也没有训练模型。
