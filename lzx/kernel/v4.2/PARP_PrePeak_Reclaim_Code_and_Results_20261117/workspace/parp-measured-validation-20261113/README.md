# 实测输入与安全档位验证版

本目录是独立新版，原四操作代码及上一轮实验均保留。本轮先完成校准和检查，再执行原三种场景的关闭／开启对照，不把准备数据混入正式结果。

- WSS来自原采集口径的 `clear_refs + smaps Referenced`，pgfault为真实内核计数。共享文件按原采集器的路径最大值合并，是共享物理页并集的下界；不宣称逐物理页精确WSS。读数失败、缺失、过期不能补成零。
- 应用内选择high/reclaim只读取WSS和pgfault数值，不读取场景名或reuse标签。默认看未来约4秒的实测窗口，属于可配置试验设置，不宣称最佳时间窗口。
- 应用间保护分仍由脚本给出。冷对象预设为GIMP未访问的旧图层、Calc未读取的旧行、Firefox未使用的旧画布；可分配字节上限来自实测保留档位，不按RSS百分比指定。
- `calibrate.py`对每个应用的high/reclaim分别下探；配对执行包含旧页、新页和完整旧文档重访的同一任务，以总缺页增长≤10%筛选。基线为零又出现额外缺页时，未约定绝对阈值则不认证该档。耗时单独报告，不擅自给用户未约定的时间硬阈值。
- 校准任务比部分正式任务多了旧文档操作；正式放行时另用最小参考任务的缺页增量预算做保守筛选，防止较大的校准基线掩盖较短任务的代价。不同场景最终仍分别与自己的关闭组核对。
- 在线脚本每0.5秒重新给出实测参考轨迹中的未来需求，结合当前真实可用额度重算缺口。它是在线回放预测器，不是已训练模型；整机需求不再固定288 MiB。当前测试域仍是四应用独立cgroup，不是耗尽整台16 GiB。
- high保持到需求变化、暂停或计划结束，不再每批达到目标就反复写回max。已测轨迹和内核写入时长决定提前放宽的时间；剩余预算为零时仍必须解除过低high。
- 每个应用的总预算、各接口预算分别受已实际测试的请求量约束。暂停、恢复、配额调整和新预测均不补满预算、不改变原到期时间。
- 保护参考同任务关闭组的refault/PSI，另看前台实际响应。暂停的是回收计划，不冻结应用执行。内核写入时间、保护暂停区间、应用操作时间分别记录；不能把三者相加称作前台卡顿时长。
- 必须开启zswap且观察到真实压缩页，才允许称为压缩实验。退出由本地root guard恢复原zswap设置。

`controller/test_measured.py`检查数值分支、校准证据、预算、预测更新及保护。`lab/formal.py`在校准证据完整且通过后，冻结源码、设置六次相同的绝对内存额度，执行正式对照。未通过的应用／路径不得分配回收量，额度不足时记录缺口。

尚未纳入这三类实机对照的内容：真实模型训练、桌面前后台动态切换、独立崩溃恢复监护、多种未知应用组合。不能据此宣称生产上线或所有场景最优。
