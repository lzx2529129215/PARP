# 路径政策

1. 正式源码目录不得写运行输出。
2. 新运行输出统一进入项目根`outputs/<subsystem>/<session_id>/`。
3. 原始数据、派生数据和报告必须分层，raw只读。
4. checkpoint进入正式模型制品目录并绑定metadata、vocab和SHA256。
5. 完整Linux内核源码按特殊外部组件管理，不与普通Python源码迁移。
6. 禁止新增用户机器绝对路径硬编码。
7. 路径优先由项目根、配置或环境变量解析。
8. 真机数据必须包含session metadata、device ID和采集时间。
9. 二进制必须记录构建版本、源码基线和SHA256。
10. 备份必须记录时间、来源和manifest。

本政策不修改任何现有绝对路径，实施需另行批准。
