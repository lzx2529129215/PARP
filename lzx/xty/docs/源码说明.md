# 源码快照说明

本目录保存当前 VM 里用于复现的关键源码文件和对应的变更前备份。
如果只想恢复当前功能，优先应用 `patches/` 下的补丁。

- `mm/vmscan.c`
  - 备份：`mm/vmscan.c.bak`
  - 作用：vmscan parp bin selection
- `mm/memcontrol-v1.c`
  - 备份：`mm/memcontrol-v1.c.bak`
  - 作用：memcontrol-v1 tier2 legacy cgroup files
- `kernel/trace/trace_events.c`
  - 备份：`kernel/trace/trace_events.c.bak`
  - 作用：trace event dereference arg guard
