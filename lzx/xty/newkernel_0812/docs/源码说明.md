# 关键源码位置说明

## 0. 编译期开关

```text
mm/parp/Kconfig
```

- `CONFIG_PARP_TIER2_WATERMARK`：编译二级 memcg 水位线、EWMA 预测器和 tier2 用户接口。
- `CONFIG_PARP_RECLAIM_BIN_SCORE`：依赖前一个开关，编译应用先验与 tier2 headroom 的 bin 评分。
- 两个开关默认是 `y`，用于复现当前已验证内核。
- 关闭水位线开关时，`mm/parp/core/watermark.c` 不编译，memcg 结构和 tier2 文件被条件排除。
- 关闭 bin 评分开关时，`mm/vmscan.c` 回到随机 `MEMCG_NR_BINS` 分配。

## 1. 二级水位线核心实现

```text
mm/parp/core/watermark.c
```

关键位置：

- `32-67`：注册 `vm.tier2_predict_*` sysctl。
- `69-79`：`parp_tier2_scaled_wmark()`，按 `limit * scale / 10000` 计算水位线。
- `81-90`：`parp_tier2_ewma_next()`，计算 EWMA。
- `92-105`：`parp_tier2_predict_ms()`，预测跌到 demote watermark 的时间。
- `108-144`：读取 memcg limit/usage/headroom，并计算 alloc/demote 水位线。
- `157-203`：预测 work 到期后执行有界主动回收。
- `271-389`：`parp_tier2_memcg_sample()`，采样、更新 EWMA、调度或取消 delayed work。
- `391-401`：memcg charge 后触发分层采样。
- `414-588`：`memory.tier2_*` 文件 show/write 实现。

## 2. 数据结构

```text
include/linux/parp_tier2.h
include/linux/memcontrol.h
```

`include/linux/parp_tier2.h:20-50` 定义 `struct parp_tier2_memcg`。

`include/linux/memcontrol.h:212-214` 把 `struct parp_tier2_memcg parp_tier2` 嵌入每个 memcg。

## 3. memcg 生命周期接入

```text
mm/memcontrol.c
```

关键位置：

- `2506`：charge 成功后调用 `parp_tier2_memcg_charge(memcg)`。
- `3785`：创建 memcg 时初始化。
- `3865`：online 时更新状态。
- `3895`：offline 时取消预测 work。
- `3941`：销毁时清理。
- `3976`：reset 时重置 tier2 状态。

## 4. cgroup 用户接口

cgroup v2：

```text
mm/memcontrol.c:4667-4711
```

cgroup v1：

```text
mm/memcontrol-v1.c:2136-2180
```

接口包括：

```text
memory.tier2_enabled
memory.tier2_alloc_scale
memory.tier2_demote_scale
memory.tier2_alloc_wmark
memory.tier2_demote_wmark
memory.tier2_headroom
memory.tier2_below
memory.tier2_stats
```

## 5. bin 评分接入 MGLRU

```text
mm/vmscan.c
```

关键位置：

- `4392-4433`：`parp_memcg_reclaim_bin()`，读取应用预测和 tier2 headroom。
- `4412-4413`：读取 `memcg->parp_tier2.limit_bytes/headroom_bytes`。
- `4422-4425`：应用分数和 headroom 分数同时存在时取 `min()`。
- `4447`：`lru_gen_rotate_memcg()` 使用评分 bin。
- `4494`：memcg online 时按评分放入 bin。
- `5377-5379`：PARP 开启后 `shrink_many()` 从 bin 0 开始扫描。
- `5386-5409`：遍历 bin 中 memcg/lruvec 并调用 `shrink_one()`。

## 6. 初始 HWE 树中的旧实现

初始树里有：

```text
mm/tier2_watermark.c
include/linux/tier2_watermark.h
```

最新 `linux-6.17.13-parp` 不再以这套旧文件作为主实现，而是迁移到
`mm/parp/core/watermark.c` 和 `include/linux/parp_tier2.h`，并通过
`vmscan.c` 的 bin 评分接到 MGLRU 回收顺序中。新增代码均带有
`/* xty-test */` 标记，便于审查和后续对照测试。
