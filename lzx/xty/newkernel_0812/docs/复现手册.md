# 从 linux-hwe-6.17-parp 复现 linux-6.17.13-parp 手册

## 1. 适用场景

这份补充包面向“别人机器上已有 v4-parp 初始内核源码”的场景。初始源码树按本机命名为：

```text
/home/xty/v4-parp/work/linux-hwe-6.17-parp
```

目标是复现最新源码树：

```text
/home/xty/v4-parp/work/linux-6.17.13-parp
```

当前运行验证过的内核版本是：

```text
6.17.13-myks-l02-kcfg-0814
```

## 2. 复现方式

这两个目录在本机属于同一个父级 git 工作区，单独目录本身不是独立仓库。因此本包采用更稳的复现方式：

```text
初始 linux-hwe-6.17-parp
  -> 删除 source/delete_paths.txt 中列出的旧文件/目录
  -> 覆盖 source/overlay/ 中的新增和修改文件
  -> 得到 linux-6.17.13-parp 对应源码状态
```

其中 `patches/0001-key-parp-tier2-bin-review.patch` 用来审查基础关键改动，
`patches/0002-parp-kconfig-switches-0814.patch` 用来审查本次编译期开关改动，
`source/overlay/` 才是复现时的权威输入。

## 3. 应用补充包

建议先复制一份初始源码树，避免直接改原目录：

```bash
cp -a /path/to/linux-hwe-6.17-parp /path/to/linux-6.17.13-parp-repro
cd /path/to/hwe-to-linux-6.17.13-parp-github-0812
bash scripts/apply_overlay.sh /path/to/linux-6.17.13-parp-repro
```

## 4. 构建

```bash
cd /path/to/hwe-to-linux-6.17.13-parp-github-0812
bash scripts/build_install_verify.sh /path/to/linux-6.17.13-parp-repro /path/to/build-linux-6.17.13-parp
```

构建完成后，在测试虚拟机内安装：

```bash
sudo make -C /path/to/linux-6.17.13-parp-repro O=/path/to/build-linux-6.17.13-parp modules_install install
sudo reboot
```

## 5. 编译期开关对照

默认配置会启用两个新增机制：

```text
CONFIG_PARP_TIER2_WATERMARK=y
CONFIG_PARP_RECLAIM_BIN_SCORE=y
```

关闭二级水位线时，`watermark.o` 不参与构建，memcg 中不再嵌入
`struct parp_tier2_memcg`，`memory.tier2_*` 文件和 `vm.tier2_*` sysctl
也不会生成；charge/lifecycle 调用通过空 stub 回到原逻辑。

关闭 bin 评分时，`parp_memcg_reclaim_bin()` 使用原来的随机
`MEMCG_NR_BINS` 分配。由于 bin 评分读取二级水位线状态，该开关依赖
`CONFIG_PARP_TIER2_WATERMARK`。

```bash
scripts/config --file /path/to/build/.config -d PARP_RECLAIM_BIN_SCORE
scripts/config --file /path/to/build/.config -d PARP_TIER2_WATERMARK
make O=/path/to/build olddefconfig
```

## 6. 运行态验证

重启后执行：

```bash
cd /path/to/hwe-to-linux-6.17.13-parp-github-0812
bash scripts/verify_runtime.sh
```

重点看：

```text
CONFIG_PARP=y
CONFIG_PARP_TIER2_WATERMARK=y
CONFIG_PARP_RECLAIM_BIN_SCORE=y
CONFIG_MEMCG=y
CONFIG_LRU_GEN=y
/proc/sys/vm/tier2_predict_enabled
/proc/sys/vm/tier2_predict_latency_ms
/proc/sys/vm/tier2_predict_horizon_ratio
/sys/fs/cgroup/.../memory.tier2_enabled
/sys/fs/cgroup/.../memory.tier2_stats
dmesg 中的 PARP tier2 ready 日志
```

## 7. 关键变化

最新内核不是继续使用初始 HWE 树里的 `mm/tier2_watermark.c`。最新实现迁移到了 PARP 子系统：

```text
mm/parp/core/watermark.c
include/linux/parp_tier2.h
```

同时，`mm/vmscan.c` 中新增 `parp_memcg_reclaim_bin()`，把应用预测分数和 `memcg->parp_tier2.headroom_bytes / limit_bytes` 合并成 bin 评分，影响 MGLRU node 级 memcg 回收顺序。
