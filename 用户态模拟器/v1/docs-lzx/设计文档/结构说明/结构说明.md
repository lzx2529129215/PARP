**CMakeLists.txt**
整个工程的**构建入口**。
它负责告诉 CMake：
- 项目使用 C11；
- 哪些 `.c` 文件属于核心静态库；
- 哪些文件编译为模拟器；
- 哪些文件编译为测试程序；
- 头文件搜索路径在哪里；
- 是否启用测试；
- 是否启用 ASan、UBSan；[[ASan、UBSan]]
- 编译时启用哪些 warning。

最终通常生成三个目标：
```
reclaim_core
reclaim_simulator
reclaim_tests
```
大致关系：
```
reclaim_core
    ↑
    ├── reclaim_simulator
    └── reclaim_tests
```
也就是说，模拟器和测试程序都链接同一个核心库，避免出现两套不同的回收逻辑。

**LICENCE**
项目开源许可证。
它规定其他人是否可以：
- 使用代码；
- 修改代码；
- 发布代码；
- 商业使用；
- 是否必须保留版权声明。
具体使用 MIT、Apache-2.0、GPL-2.0 等需要根据你的开源计划确定。
如果未来代码要进入 Linux 内核，许可证兼容性尤其重要。当前第一阶段可以先选一个明确许可证，但不能随意复制 Linux 内核 GPL 代码到不兼容许可证项目中。
