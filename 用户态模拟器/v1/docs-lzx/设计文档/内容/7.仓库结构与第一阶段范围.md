## 第一阶段实际实现
本轮只实现：
```text
C11通用核心
CMake + CTest
单线程确定性事件引擎
page和domain哈希索引
传统per-cgroup四链Shadow LRU
G1简化老化
AGE_GROUP / AGE_ALL
RECLAIM_GROUP / RECLAIM_ALL
priority动态扫描压力
swappiness与swap_enabled
folio order和基础页统计
候选隔离—模拟执行—putback
默认成功与单次失败注入
逐事件一致性检查
文本trace回放
完整单元与场景测试
```

## 第一阶段明确不实现
```text
真实物理页回收
Linux内核模块
OpenHarmony内核修改
真实swap/writeback/unmap
多线程并发
完整Linux active/inactive老化
MGLRU
预测模型接入
LSTM和Markov逻辑
memory.min / memory.low
NUMA多node和多zone
Shadow与真实全局LRU同步钩子
```
这些不是取消，而是后续独立阶段。

# 最终核心原则

```text
真实全局LRU
= 页面事实状态与执行权威

Shadow per-cgroup LRU
= cgroup视角的辅助索引和策略建议

通用核心
= 平台无关的数据结构与决策逻辑

执行器适配层
= 将建议交给模拟器或真实内核

内核原有回收机制
= 完成隔离、回写、换出、解除映射和释放
```
