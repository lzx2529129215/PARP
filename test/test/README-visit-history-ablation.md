# 双窗口模型历史长度与显式特征离线对比

运行：

```bash
python3 -m unittest discover -s test/test/tests -p test_visit_explicit.py
python3 -u test/test/run_visit_history_ablation.py --output-dir test/outputs/visit-history-ablation-new
```

六组：5、10、20段历史，分别关闭/开启显式特征。原始checkpoint和在线服务保持原样。
默认每组20轮、batch 2048、Adam lr 0.001、seed 42、CPU两线程；同一独立打乱生成器保证每轮训练样本顺序相同。
各组从头训练，按验证集原始双窗口掩码损失选择epoch。使用验证集后台30秒AP比较方案，测试集不参与选择。
这是一轮单seed消融，不是多seed显著性验证。

数据来自现有visit_window_v1的train/val/test.csv及segments.csv。锚点、标签、未知掩码、打开集合、时间划分均原样复用。
只拓展过去历史，不重采样，不读取当前片段的最终时长。相同时间戳的切换按源片段顺序匹配旧历史。
运行时逐行断言扩展历史的最后5段与旧序列完全一致；原序列刚切入的1秒时长下限保留，各组一致。
显式特征按真实时间计算，刚切入的年龄为0；旧序列的1秒下限并非未来停留观测。

新增显式特征（每个词表应用）：

- 最近进入、最近离开距今时长及是否在可见历史中观测到的掩码。
- 可见历史内最近60、180、600秒进入次数，以及可见历史内总出现次数。
- 最近一次停留时长；当前片段只计已发生的时长。
- 与当前应用之间的双向相邻切换次数。
- 当前历史覆盖秒数，以及是否覆盖完整60、180、600秒窗口。

每组只从自己的5/10/20段计算显式特征，不额外查询更早的事件。缺失不代表刚刚访问；时间值附观测掩码。
计数除以固定20，不按组长度重新缩放。年龄log1p截断3600秒、停留log1p截断600秒；序列仍使用旧600秒归一化。
显式特征经过32维MLP产生双logit残差，加到原LSTM输出；嵌套sigmoid保持p30<=p180。
增加的模型容量会写入parameter_count，效果不能完全归因于某个单独特征。
新显式模型使用独立model_type，checkpoint包含特征名、历史长度、归一化、词表和源文件哈希；不安装到旧在线入口。

每组保存checkpoint.pt、训练曲线、val/test概率缓存与evaluation.json。
顶层progress.json原子更新，REPORT.md/summary.json在每组结束后更新。
主要比较后台候选30秒AP、Brier、Top1/Top2精确率与召回率、0.8/0.9热名单覆盖、180秒冷访问率与覆盖。
Top-k仅作排序诊断，未达到置信阈值的应用不会因此被定义为热应用。所有质量指标排除未知标签。
更长历史仍在同一会话内；会话开头不足指定长度时padding，并报告实际有更长历史的样本数。
